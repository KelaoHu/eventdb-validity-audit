# 自建事件库（黄金标准）

人工整理并多源核查的 **712 条重大双边事件**（2002-01 起，中国 × 25 个贸易伙伴，17 个类别），
是论文第二层（命中率/响应效度）与事件研究的独立外部基准。

## 文件清单

| 文件/目录 | 说明 |
|---|---|
| `自建事件库_25国_17类_712条事件.csv` | **现行版本**（2026-07-28 起）：剔除 1 条 2001-10 日本越界事件 |
| `自建事件库_25国_17类_713条事件.csv` | 旧版存档（含该越界事件），**勿用于新分析** |
| `verify_sources.py` | 事件来源核查脚本 |
| `source_verification_report.csv` / `_summary.json` | 核查结果：每条的来源与核验状态 |
| `事件备份\` | 构建过程中的历史版本备份 |

## 结构与口径
- 字段（以 events_712 为准）：country_en/country_cn、event_date（精确到月）、event_name、
  event_type_original（17 类；leader_visit 细分出访/来访/第三方会晤/远程通话，共 434 次领导人互动）、
  event_category、impact（正面/负面/中性）、visit_level、visit_direction
- 来源以官方与主流媒体为主（外交部网站 410 条、中国日报 50 条、中国政府网 33 条、新华社 29 条）
- 下游各套件读取的是 `02_中间数据_分数与面板\月度分数\events_712.csv`（同一文件的管线副本）
