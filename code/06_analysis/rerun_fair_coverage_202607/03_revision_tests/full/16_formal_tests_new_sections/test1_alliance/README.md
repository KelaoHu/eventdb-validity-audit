# 16-检验1 美国盟友 × 负面事件暴露：正式交互检验

## ① 检验目的与对应初稿问题

初稿 4.5 节（M3 模块，`3.2 双边关系分析基于月度政治分数\全新事件研究法\03_联盟政治与美国盟友对华反应同质性`）声称：美国盟友对华负面事件对双边政治分数的平均冲击约 **-0.41**，非盟友接近 0，即盟友反应具有同质性且显著强于非盟友。但 M3 仅为分组均值对比（`robustness/m3_robustness_ally_sets.csv`），无任何显著性推断。本检验将其升级为正式的面板交互回归 + 置换检验。

## ② 数据与模型设定

- 数据：`全新事件研究法\data\` 下 `scores_v3_GDELT_ICEWS_2025.csv`（25 国 × 288 月，2002-01~2025-12，GDELT/ICEWS 两库）与 `events_713.csv`（713 条黄金标准事件）。
- 事件暴露口径与 M3/M7 完全一致：剔除 `leader_visit`（435 条，均为 neutral/positive 礼仪性事件），保留 168 正 / 110 负条非访问事件，按国家×月聚合为暴露虚拟变量（271 个暴露单元：107 负、164 正）。
- 盟友名单沿用 M3 `code/generate.R`：**日本、韩国、澳大利亚、英国、加拿大、菲律宾**（6 国）；稳健性用窄名单（仅亚太双边共同防御条约盟友：日、韩、澳、菲）。
- 主设定（与 M3 shock 口径一致的局部投影）：
  y_{i,t,h} = score_{i,t+h} − mean(score_{i,t−1..t−3})，
  y = β1·NegExp + β2·NegExp×Ally + γ1·PosExp + γ2·PosExp×Ally + Country FE + Year-Month FE，
  双向聚类（country + month），h = 0..6。Ally 主效应被 Country FE 吸收（时间不变），交互项识别。R `fixest::feols`。
- 稳健性设定：因变量取 score 水平值（结果见 CSV `spec=level`，结论方向相同但水平设定受事件自选择于分数水平的影响，解读从略）。
- 置换检验：500 次随机重抽 6 国作为"伪盟友"（保持盟友数=6），重估交互项，对主设定 h=0 与 h=1 报告置换 p。

## ③ 结果解读（新数字，GDELT 主设定）

| h | 非盟友暴露效应 β1 | 交互项 β2 | 盟友总效应 β1+β2 | n |
|---|---|---|---|---|
| 0 | **-0.419 (p=0.015)** | -0.022 (p=0.917) | **-0.441 (p=0.0005)** | 7175 |
| 1 | -0.009 (p=0.937) | **-0.451 (p=0.0046)** | **-0.460 (p<0.0001)** | 7150 |
| 2 | +0.090 (p=0.529) | -0.218 (p=0.141) | **-0.129 (p=0.014)** | 7125 |
| 3 | -0.066 (p=0.592) | -0.150 (p=0.277) | **-0.216 (p=0.013)** | 7100 |
| 4–6 | 均不显著 | 均不显著 | 均不显著 | ≈7000 |

置换检验（GDELT，500 次）：h=0 交互项双侧置换 p=0.934（毫无差异）；**h=1 交互项双侧置换 p=0.042、单侧 p=0.022**（差异真实，非随机盟友分组可得）。

稳健性：窄名单（4 国）下 h=1 交互项 **-0.516 (p=0.0002)** 更强；但 ICEWS 库下 h=0 交互项 +0.043 (p=0.893)、h=1 交互项 -0.285 (p=0.363)，**盟友差异在 ICEWS 中不复现**（ICEWS 中盟友与非盟友 h=0 冲击分别为 -0.686 与 -0.729，几乎相同）。

三点结论：
1. **M3 的原始断言在 h=0 上不成立**：当期冲击上盟友与非盟友几乎相同（GDELT：-0.44 vs -0.42；交互项 p=0.92，置换 p=0.93）。M3 看到的"非盟友≈0"是事件级均值口径（相对事前基线、不按月份对照）的表象，正式回归（含月份 FE 对照）下非盟友当期同样显著下跌。
2. **盟友差异真实存在于冲击的"持续性"而非"当期幅度"**：h=1 时非盟友已回弹（-0.009），盟友仍深陷（-0.460），交互项 -0.451（p=0.0046，置换 p=0.042），h=2–3 盟友总效应仍显著为负。该发现在窄盟友名单下更强。
3. **但持续性差异只在 GDELT 中显著，ICEWS 不支持**（h=1 交互项 p=0.363），跨库稳健性不足。

## ④ 文本修改建议（写入 4.5 节草稿）

> "正式交互检验表明，盟友与非盟友对负面事件的**当期**政治分数冲击并无显著差异（GDELT h=0：交互项 β=-0.022，p=0.917；500 次置换 p=0.934），两组当期均显著下跌约 0.42–0.44；真正的盟友差异体现在冲击的**持续性**上：事件次月非盟友响应已回落至零（β=-0.009，p=0.937），而美国盟友仍维持显著负响应（盟友总效应 -0.460，p<0.0001；交互项 -0.451，p=0.0046，置换 p=0.042），且持续至事件后 2–3 个月。需要说明的是，该持续性差异在 ICEWS 库中不显著（h=1 交互项 p=0.363），故本文将其作为 GDELT 口径下的提示性证据而非稳健结论。"
