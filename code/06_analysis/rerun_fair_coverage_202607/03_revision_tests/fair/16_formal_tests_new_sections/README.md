运行环境：R 4.6.1（`C:\Program Files\R\R-4.6.1\bin\Rscript.exe`），包：tidyverse、lubridate、fixest。各脚本在自身 `code/` 目录下运行（`Rscript <脚本名>`）。数据只读引用 `3.2 双边关系分析基于月度政治分数\全新事件研究法\data\`，未修改任何既有文件。
