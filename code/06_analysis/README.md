论文全部估计与检验的代码与结果。四个子套件：

| 子目录 | 内容 | 对应正文 |
|---|---|---|
| `事件研究套件\` | 9 个主题模块（各 `code\generate.R` + `results\` + README.txt） | 4.2 命中率、4.5 各组证据、模块图 m1–m8 |
| `PPML套件\` | 01_连续分数PPML（基准传导/方向分解/干净面板/AR1/频率扫描/前向效应/信噪比）+ 02_事件驱动 + 03_响应速度 | 4.3、4.4、效度地图 |

| `重跑_公平覆盖期_202607\` | 上述套件的 full/fair 双口径镜像 + **对比总账** | v8 全部 fair 口径数字的权威来源 |

## 数字权威顺序（重要）
**重跑 fair > 重跑 full > 模块历史存档**。
2026-07-28 事件库 713→712 修订使事件研究套件存档结果（07-23 前）与现行管线存在版本差——
引用任何存档数字前先查 `重跑_公平覆盖期_202607\对比总账\compare_summary.csv` 的 G1 列：
- `PASS` = 存档可由现行管线逐格复现，可放心引用
- `DIFF` = 存档为旧版 vintage，须改用重跑值（差异明细见 `对比总账\G1DIFF_*.csv`）

## 运行方式
R 脚本：`"/c/Program Files/R/R-4.6.1/bin/Rscript.exe" generate.R`（全路径必须）。
套件脚本内数据路径为绝对路径，迁移机器后需批量替换（见 `06_环境说明\复现步骤.md` 阶段 0）。
