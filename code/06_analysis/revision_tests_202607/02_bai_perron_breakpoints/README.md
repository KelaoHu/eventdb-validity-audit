# 02 结构性断点正规检验（Bai-Perron）

## ① 目的与对应初稿问题（C3）

初稿 4.2 节（draft_full.txt 第 [130] 段）称：

> "模块 2 在 12 个国家的双边关系中识别了 21 个结构性断点——即政治指数序列的统计上不可逆的水平偏移。其中，澳大利亚的中澳关系呈现阶梯式下降模式：GDELT 政治指数在 2007 年清洁煤合作协议破裂、2015 年 FTA 签署和 2018 年华为 5G 禁令三个事件前后分别发生了不可逆的水平下降——从 0.88→0.20→-0.01→-0.81——每一阶段的持续性不断加强（AR(1) 自相关从 0.35 升至 0.67）……菲律宾……在 2012 年黄岩岛事件、2016 年南海仲裁案、2023 年水炮事件后急剧下挫……"

但现行 02 模块的 `generate.R` 实为"6 个月滚动波动率 > 全样本均值+2SD"的计数器（breakpoints.csv：GDELT 21 国 / 293 个高波动月），既非水平断点检验，也无"不可逆"概念。本任务用 Bai-Perron 正规断点检验重做，并核对澳大利亚、菲律宾两个案例国。

## ② 数据与方法

- 序列：`全新事件研究法/data/scores_v3_GDELT_ICEWS_2025.csv` 中 `db=="GDELT"` 的 `value` 列（已逐值核对：与 `3.1` 目录 `GDELT_Geometric_Mean_月度指数` 的 `Index_Type=="Aggregated"` 完全一致，即几何平均 Aggregated 版本），25 国 × 288 个月（2002-01—2025-12）。
- 主检验：`strucchange::breakpoints(value ~ 1, h = 12)`（均值水平断点，最小分段 12 个月），断点数由 BIC 选择（`breakpoints(bp)` 默认）。
- 稳健性：各国序列 AR(1) 系数高达 0.06–0.72（均值约 0.34），序列相关会扭曲 BIC 选择。按 Bai-Perron 标准处理，对 AR(1) 预白化序列（y_t − φ·y_{t−1}）重复同一检验。
- 案例国：按预白化-BIC 分段，报告各段水平均值、段内 AR(1)（OLS）、半衰期（log0.5/logφ，单位：月）；并对照 `events_713.csv` 中每个断点 ±3 个月内的事件。
- 代码：`code/task02_bai_perron.R`；结果：`results/breakpoints_bai_perron.csv`、`results/case_australia_philippines.csv`；图：`figures/breakpoints_Australia.png`、`figures/breakpoints_Philippines.png`（320 dpi，英文标注）。

## ③ 结果解读（新数字 vs 初稿旧数字）

**逐国断点（results/breakpoints_bai_perron.csv）：**

- 主检验（原始水平，BIC）：25 国共 **89 个断点、24 国 ≥1 个**（仅西班牙为 0）。
- 稳健性（AR(1) 预白化，BIC）：25 国共 **31 个断点、19 国 ≥1 个**。
- 初稿称"12 国 21 个统计上不可逆的水平偏移"——在两种口径下均无法复现（89/24 国或 31/19 国），且 Bai-Perron 框架没有"不可逆"这一统计概念；分段均值有升有降（如菲律宾 0.66→−1.23→+0.16→−2.12；印度 1.87→0.50→−0.83 后又回升），并非单向"水平锁定"。

**澳大利亚（case 表）：** 预白化-BIC 仅识别 **1 个断点：2017-12**（±3 个月内 713 事件：2017-12 Foreign Interference Laws，negative）。两段均值 **+1.259 → +0.045**（初稿：0.88→0.20→−0.01→−0.81 的四段阶梯——不存在）；段内 AR(1) **0.253 → 0.600**，对应半衰期 **0.50 → 1.36 个月**。"持续性上升"方向与初稿（0.35→0.67）定性一致，但半衰期仅约 1.4 个月，与"每次下降都使下一次恢复更加困难/不可逆"的叙事完全不符。原始-BIC 口径下澳有 5 个断点（2003-08、**2007-01**、2017-12、2020-04、2022-05）：其中 2007-01 与初稿"清洁煤协议破裂"月份重合，但 events_713 中该事件实为"中澳清洁煤技术联合协调小组启动"（**正面**事件，初稿史实错误）；2015 年 FTA、2018 年华为禁令附近均**无**断点。

**菲律宾（case 表）：** 预白化-BIC 识别 **3 个断点：2010-05、2016-05、2023-07**，四段均值 **+0.658 → −1.229 → +0.157 → −2.125**，段内 AR(1) 0.08 / 0.25 / 0.39 / 0.14（半衰期均 < 1 个月）。2016-05 断点 ±3 个月内对应南海仲裁案裁决（2016-07，negative），2023-07 断点对应仁爱礁水炮事件（2023-08，negative）；2010-05 无 713 事件对照。均值上下翻转的模式与初稿"事件驱动的高波动过山车"定性相符，但 2012 黄岩岛事件附近无断点，且各段持续性极低（冲击一个月内衰减过半），不存在"制度锁定"。

## ④ 文本修改建议

1. **删除**"模块 2 在 12 个国家的双边关系中识别了 21 个结构性断点——即政治指数序列的统计上不可逆的水平偏移"整句。可替换为（若保留该发现）："Bai-Perron 均值断点检验（最小分段 12 个月、BIC 选断点数）在 25 国 GDELT 月度政治指数中识别出 31–89 个水平断点（取决于是否对序列相关做预白化），断点集中在 2016–2023 年的地缘政治紧张期；分段均值上下双向变动，不存在普遍的不可逆水平锁定。"
2. **改写**澳大利亚案例：删除"2007 年清洁煤合作协议破裂"（史实错误：2007-01 为中澳清洁煤技术联合协调小组**启动**，正面事件）与"0.88→0.20→−0.01→−0.81"阶梯。可改为："中澳关系 GDELT 指数存在一个统计上显著的水平下移（2017-12，恰逢澳《反外国干涉法》出台），段均值由 +1.26 降至 +0.05，段内持续性（AR(1)）由 0.25 升至 0.60，但半衰期仅从 0.5 个月升至 1.4 个月——下降是持久的低水平均衡而非动态不可逆。"
3. **保留但限定**菲律宾叙事：过山车模式获支持（3 个断点、均值上下翻转、两段负向断点与 2016 仲裁案、2023 水炮事件在 ±3 个月内对应），但需删去"2012 年黄岩岛事件"作为断点触发（无对应断点），并补充各段冲击半衰期均不足 1 个月这一限定。
