# 08b 新版基准上的安慰剂检验 9 组合（对应初稿核查问题 C13）

## ① 检验目的与对应初稿问题

初稿 [135] 称"国家标签置换（200 次）、随机正态冲击（200 次）和时间块置换（200 次）的全部 9 种组合中，安慰剂 p 值均为 0.000"。核查（C13）发现该安慰剂只在**旧版**（旧估计 0.0131）上做过，新版基准（GDELT 总贸易 h=0，β=0.0127）上从未运行。本检验在新版基准上重跑：3 类置换 × 3 因变量（9 组合）× h=0..6，每组合 200 次。

## ② 数据与模型设定

- 基准管线与 `01_连续分数PPML/01_基准传导_季度冲击/R语言工程文件/01_run_irf.R` 完全一致（逐国 z-score → 逐国 AR(1) 残差 u_Agg → fepois，控制 ln_GDP_product+ln_ER+FTA_Dummy，FE=ISO+YearMonth，cluster=~ISO）。已核验真值 IRF 复现基准：总贸易 h=0 β=0.01274 (p=0.0262)。
- 三类置换（实现口径沿用旧版 `05_Placebo_Tests.R`）：
  1. **Country_Label_Permutation**：同一 YearMonth 内、支持域国家间重排冲击值（保持边际分布，破坏国家-冲击对应）；
  2. **Random_Shock**：支持域观测上 iid N(0,1) 随机冲击；
  3. **Time_Block_Permutation**：逐国内支持连续段按 12 个月为块重排（保持国内自相关结构，破坏时间对应）。
- 每次置换重算 1..6 月滞后，估计 3 因变量 × h=0..6 共 21 个 fepois；3 类 × 200 次 = 600 任务、12,600 个模型，parallel PSOCK 并行（seed=20260726）。安慰剂 p = #{|β_placebo| ≥ |β_true|} / 200（双侧）。
- 代码：`code/08b_placebo_new_spec.R`；输出：`results/placebo_new_spec.csv`（63 单元汇总）、`results/placebo_draws.csv`（12,600 条置换系数，可逐条追溯）。

## ③ 结果解读

h=0 的 9 组合（初稿引用口径）：

| 置换类型 | 总贸易 | 出口 | 进口 |
|---|---|---|---|
| 国家标签置换 | 0.000 | 0.000 | 0.000 |
| 随机正态冲击 | 0.000 | 0.000 | 0.000 |
| 时间块置换 | **0.005** | **0.005** | **0.005** |

- 全部 63 个单元（9 组合 × 7 horizon）中，安慰剂 p 最大为 0.020（国家标签置换-出口-h=2；时间块置换-出口-h=3、进口-h=2），绝大多数单元为 0.000；置换分布均以 0 为中心（|perm_mean| ≤ 0.001，SD≈0.003–0.005），真实系数（0.0127–0.0157）位于置换分布的极端尾部。
- 结论层面**成立且更强**：新版基准上 GDELT 贸易效应通过全部安慰剂检验。
- 数字层面**不完全等于初稿**：初稿称 9 组合 p 均为 0.000，实际时间块置换 3 个组合在 h=0 为 p=0.005（200 次中 1 次超过真值），非严格的 0.000。
