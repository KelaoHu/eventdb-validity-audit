# 08c 访问效应排除疫情期

## ① 检验目的与对应初稿问题（C13）

初稿 [145] 称"排除疫情期后制裁和访问效应的方向与显著性不变"（疫情期=2020.01–2021.06，见 [114]），但访问效应的排除疫情期估计无输出可溯源（C13）。本子检验按 02 模块设定剔除 2020.01–2021.06 后重估出访/来访/远程通话三系数。

## ② 数据与模型设定

- 与 `02_事件驱动PPMLHDFE/02_正负向非对称与4类访问效应` 模型 2 完全一致：`fepois(trade ~ V_RemoteTalk + V_China_Outbound + V_Partner_Inbound + ln_GDP_product + ln_ER + FTA_Dummy | ISO + YearMonth)`，cluster=~ISO，参照组=第三方会晤，三因变量。
- 唯一差异：剔除 YearMonth ∈ [2020-01, 2021-06] 的月份（6685 → 6235 行）。同时输出全样本行以便对照。
- 代码：`code/08c_visit_effects_excl_covid.R`；输出 `results/visit_effects_excl_covid.csv`（18 行）。

## ③ 结果解读

进口维度（初稿引用维度），全样本 → 排除疫情期：

| 变量 | 全样本 | 排除疫情期 | 变化 |
|---|---|---|---|
| V_RemoteTalk | −0.0850 (p=0.006) | **−0.0998 (p=0.012)** | 仍显著为负，绝对值略增大 |
| V_China_Outbound | 0.0584 (p=0.001) | **0.0563 (p=0.002)** | 几乎不变 |
| V_Partner_Inbound | 0.0297 (p=0.148) | **0.0277 (p=0.172)** | 仍不显著 |

总贸易与出口维度方向与显著性同样全部不变（远程通话 Total −0.1313→−0.1533 (p=0.0001)、Exports −0.1807→−0.2055 (p<0.0001)，均更负）。

**结论：** "排除疫情期后访问效应方向与显著性不变"成立。值得注意：剔除疫情高峰期后远程通话负效应**反而更大**，与"远程通话负效应来自疫情期伴生危机混淆"的解释（见 05）方向相反，进一步削弱混淆假说。
