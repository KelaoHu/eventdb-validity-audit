# 10 截断反事实与低密度披露表

## ① 检验目的与对应初稿问题

初稿 4.5 稳健性一节引用了"截断反事实"与"事件密度分位"两类检验的结论，但未披露具体数字与设定，评审报告（C系编号）要求补充可核查的披露表。本文件夹直接整理既有结果（只读引用，未重跑），形成可引用的披露表。

## ② 数据与模型设定

数据源：`3.4 多个开源数据库的内容评估\新数据库异质性分析\06_政治经济效应异质性\`，两个文件：

1. `truncation_counterfactual_GDELT.csv`：GDELT 连续分数 PPML 局部投影 IRF（h=0~6），将样本分别截断至 2019-03（排除疫情期，n≈5155）与 2023-04（排除末期，n≈6331），检验基准结论对样本窗口的敏感性。25 国，双向固定效应。
2. `event_density_quantile_effects.csv`：按国家事件密度分低/中/高三组（q_Low、q_Medium 相对 q_High 基准组），加入 GDELT 分数 × 密度组交互项，检验低密度国家是否驱动基准结果。25 国全样本（n=6906）。

## ③ 结果解读（新数字）

### 截断反事实（GDELT）

| 样本 | 出口 h=0 | 进口 h=0 | 总贸易 h=0 |
|---|---|---|---|
| 截断至 2019-03 | +0.0003（p=0.930，不显著） | +0.0113（p=0.024，**） | +0.0044（p=0.178，不显著） |
| 截断至 2023-04 | +0.0109（p=0.008，***） | +0.0098（p=0.203，不显著） | +0.0091（p=0.054，*） |

关键事实：
- **GDELT 的进口正效应在排除疫情期（2019-03 截断）后依然显著且全 h=0~6 均显著**（β≈0.011–0.014，p<0.05 全期），说明进口正效应并非疫情期伪影。
- 出口正效应则在截断至 2019-03 后消失（h=0~6 全不显著），仅在含疫情后期的样本中出现——出口效应的时间稳健性弱于进口。
- 两截断样本下总贸易均为正但仅边际显著（p≈0.05–0.18）。

### 事件密度分组

- 基准组（高密度国家）：GDELT 对总贸易 +0.0176（p=0.056）、出口 +0.0252（p=0.003）显著为正；进口不显著。
- **低密度组交互项显著为负**：总贸易 -0.0231（p=0.002）、出口 -0.0338（p=0.0001）——即低密度国家的分数-贸易弹性显著小于高密度国家，两组合成后接近零。
- 含义：基准正效应主要由事件记录密度高的国家驱动，**低密度国家不构成正效应的来源**；初稿若曾暗示"低密度国家同样受益"须删除。

## ④ 文本修改建议

- 4.5 稳健性节增补一段：
