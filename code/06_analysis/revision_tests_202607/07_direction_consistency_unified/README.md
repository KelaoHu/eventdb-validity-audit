# 07 方向一致率口径统一

## ① 检验目的与对应的初稿问题（C6）
初稿三处方向一致率互相矛盾或无法溯源：摘要"四库方向完全一致比例逐国中位数约为 22%（三库为 29%）"（22% 无出处）、引言"综合全部 25 国和四库全部配对，四个数据库在所有月度观测中方向完全一致的比例仅为 7%"、4.1"逐国中位数约为 22%（四库）"。本检验选定统一口径并重算全部衍生数字。

## ② 数据与方法
- 数据：`3.4 新数据库异质性分析/00_数据与配置/panel_four_databases_2002_2025.csv`（Pol_Agg 四库月度分数），窗口 2002-01~2019-03（与 Layer 1 公共窗口一致）。
- **主口径（新口径）**：复现新 05 模块方法——逐国计算各库月度方向（+1/-1/0），**仅在所有参与库方向均非零的月份**计算完全一致率；1M 窗口为主、2M 对照。实现经校验：11 国四库 pooled=0.2923、N=561，与新 05 模块 `direction_consistency_summary.csv` 完全一致。
- 旧口径对照引自 `旧数据库异质性分析/08_方向性检查`（零变化月保留在分母；四库含清华 75% 零变化月，故四库仅 7.24%）。
- 结果：`results/direction_consistency_unified.csv`（汇总）、`results/_bycountry_3db_2002_201903.csv`、`results/_bycountry_4db_2002_201903.csv`（25/11 国逐国明细）。

## ③ 结果解读
| 指标 | 新口径（主） | 旧口径（对照） |
|---|---|---|
| 三库 25 国完全一致率（1M） | pooled 31.3%／逐国中位数 30.6% | pooled 29.3% |
| 四库 11 国完全一致率（1M） | pooled 29.2%／逐国中位数 28.6% | pooled 7.24% |
| 日本：三库／四库 | 39.8%／29.1% | — |
| 巴西三库 | **26.2%**（无条件 24.6%） | 23.9% |
| 印尼三库 | 36.5% | — |

关键判断：
1. **"22%" 在任何口径下都不存在**，必须弃用。
2. 引言"仅 7%"是旧口径（清华零变化月入分母）数字，与新口径（29.2%）差 4 倍——两个口径回答不同问题：旧口径衡量"全部月份中四库同向的月份占比"（清华 75% 月份无变化拉低），新口径衡量"有信号月份中的共识度"。**建议正文统一用新口径，旧口径数字移附录并解释差异**。
3. 初稿的日本（40%/29%）恰好与新口径吻合，说明初稿部分段落已用新口径、部分用旧口径，混用是矛盾根源。
4. 巴西"三库约 15%"无出处：新口径 26.2%、旧口径 23.9%，都不是 15%。
