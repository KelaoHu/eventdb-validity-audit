# 09 FTA 基准效应

## ① 检验目的与对应的初稿问题（C10）

初稿摘要（draft_full.txt [1]）声称"FTA 生效在较短周期内亦未对贸易产生显著提振"，但正文（3 节方法与 4 节结果）从未报告任何 FTA 效应检验——FTA_Dummy 只作为控制变量出现。本检验为这一摘要断言补上证据：基准 FTA_Dummy 回归 + FTA 生效前后逐月事件研究。

## ② 数据与模型设定

- 面板：25 国月度 2002-01~2025-10（`新PPMLHDFE/data/panel_clean.csv`，n=6,685），三因变量 Trade_Total / Trade_Exports / Trade_Imports。
- **基准**：`fepois` PPML，trade ~ FTA_Dummy + ln_GDP_product + ln_ER | ISO + YearMonth，双向聚类（ISO + YearMonth）。
- **事件研究**：FTA 生效前后逐月虚拟变量 k=-6..+12，基期 k=-7；同一 PPML-FE 设定与双向聚类。样本内发生 FTA 生效的处理组 8 国：ID/PH/SG/TH/VN（2007-07，中国-东盟 FTA）、AU/KR（2015-12）、JP（2022-01，RCEP）；16 国从未处理作对照；MY 面板起点（2015-01）即 FTA=1、无生效前观测，从事件研究剔除（基准回归保留）。生效时点由面板中 FTA_Dummy 的 0→1 跳变识别，与 WTO RTA 编码一致。
- 代码：`code/09_fta_effects.R`、`code/09b_plot_fta_event_study.R`；结果：`results/fta_effects.csv`、`results/fta_event_study.csv`；图：`figures/fta_event_study.png`（300dpi，英文标注）。

## ③ 结果解读

**基准 FTA_Dummy（n=6,685，25 国）**：

| 因变量 | β | se | p | exp(β)-1 |
|---|---|---|---|---|
| 总贸易 | -0.1030 | 0.0770 | 0.1813 | -9.78% |
| 出口 | -0.0140 | 0.0615 | 0.8196 | -1.39% |
| 进口 | -0.1381 | 0.1000 | 0.1674 | -12.90% |

三个系数均不显著且点估计为负——摘要"未显著提振"的断言得到支持。

**事件研究（n=6,558，24 国）**：生效后 12 个月（k=0..+12）无一系数显著为正。总贸易在 k=+4（-0.1078, p=0.0266）与 k=+7（-0.0894, p=0.0095）显著为负；出口在 k=+1（-0.1592, p=0.0084）、k=+5/+6（-0.1156/-0.1153, p=0.0137/0.0237）、k=+7（-0.1129, p=0.0077）、k=+8（-0.0974, p=0.0395）、k=+11（-0.1052, p=0.0091）显著为负；进口各月均不显著。两点注意：(i) 生效前 k=-5（总贸易 -0.0786, p=0.0433）与 k=-6（p=0.0835）已显著/边缘显著为负，存在一定前趋势——FTA 签署/生效常发生在双边贸易相对下行期（与初稿 [143] 对经贸互利合作事件内生性"签署是对下降的应对"的讨论一致），故事件研究的负系数不应解读为 FTA 的因果损害，但足以排除"短期显著提振"；(ii) 生效当月（k=0）三个维度均不显著，无即时效应。

## ④ 文本修改建议

摘要 [1] 原句"FTA 生效在较短周期内亦未对贸易产生显著提振"可保留，但建议补数字并限定口径，同时在 4.4 或 4.5 新增一句正文证据：

"[1] 改为：'FTA 生效在较短周期内亦未对贸易产生显著提振（PPML-HDFE 基准：总贸易 β=-0.1030, p=0.1813；出口 β=-0.0140, p=0.8196；进口 β=-0.1381, p=0.1674；生效后 12 个月的事件研究系数无一显著为正）。'

正文建议新增（4.4 末或 4.5）：'以 FTA 生效当月为事件时点的事件研究（k=-6..+12，基期 k=-7，8 次样本内生效事件）显示，生效后 12 个月内无任何月份出现显著正效应；出口维度在生效后多个月份显著为负（如 k=+1: β=-0.1592, p=0.0084），但总贸易与进口在多数月份不显著。鉴于生效前 k=-5/-6 已现负系数，FTA 生效往往伴随贸易相对走弱，事件研究的负系数不宜作因果解读；可以确定排除的是"生效后一年内显著提振"这一传统预期。'"
