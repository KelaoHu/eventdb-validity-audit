## 二、审计口径定义

- **全期口径**（v7 现状）：各库用其名义全期面板，ICEWS 含 32–33 个月填充、Phoenix 含 9 个月填充。
- **公平覆盖期口径（trunc）**：ICEWS 样本/事件限于 ≤2023-04，Phoenix 限于 ≤2019-03，GDELT/清华不变。细分三变体：A 全期复制（验证存档）；B 截断样本+全期 z-score/AR(1)；C 截断样本+截断段内重算 z-score/AR(1)（最干净，报告以 C 为准）。
- **公共窗口口径**：≤2019-03，四库同题同卷。

## 五、核心结论

1. **唯一结论级问题是命中率叙事**（#1/#3/#6）：v7 的全期口径让 ICEWS 的 42 个填充段事件（712 中 2023-04 后者）机械不命中，人为压低 ICEWS 至垫底。公平口径下四库命中率高度接近（公共窗口差异 <1pp），"GDELT 命中率最高"依然成立但优势从 11.8pp（对 ICEWS）缩至 2.2pp，且需要限定"按各库真实覆盖期"才有意义。
2. **所有因果/稳健性结论在截断口径下全部保持**（PPML n.s.→n.s.、Wald 0.019→0.025、联盟交互 −0.451**→−0.432*、溢出 null→null、M5 梯度、h=0..6 全 n.s.）——本文第三层核心叙事（"只有 GDELT 的政治信号进入贸易决策"）不受污染影响，反而因 ICEWS 截断后仍不显著而更干净。
3. **para 27 声明与管线不符是必须修复的硬伤**（审稿人一旦抽查 n=6683 vs 截断声明即穿帮），修复方向只有两种，见下。

## 六、修复路径（待用户拍板）

**选项 A：重算对齐声明（推荐）**——按 para 27 已有声明执行：
- PPML/命中率/test1-3/M5/M7 的 ICEWS（及 Phoenix）规格全部重跑截断口径（本模块脚本已就绪，半天工作量）；
- 正文 para 1/76/82/94 数字替换，命中率表改为"各库真实覆盖期"口径并加公共窗口对照列；
- 命中率排序叙述重写为"GDELT 居首但四库差距收窄/公共窗口基本持平"。
- 代价：摘要与 §4.2 两段叙事改写；附录 S3 全表重生成。

**选项 B：改声明措辞**——保留全期数字，删改 para 27"以截断为准"为"含填充期，结论已按截断稳健性核对"：
- 工作量最小，但命中率节必须补充"ICEWS 填充段 42 事件机械不命中"的诚实披露，否则审稿人复算即发现 56.5% 垫底是人工产物；
- 风险：把"测量选择塑造结论"的核心论点建立在一个被填充污染的对照上，削弱 §4.2 说服力。
