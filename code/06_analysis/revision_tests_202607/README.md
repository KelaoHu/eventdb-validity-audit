# 修订补充检验（2026-07）总说明

本目录汇总对论文初稿全部定量主张的补充检验与修正结果，配套文件：
- **《311工程论文评审报告.md》**（桌面）：60 条定量主张的核查结论与 C#/M# 问题编号；
- **《311工程论文_逐段修改对照表.md》**（桌面）：按章节组织的最终修改方案；
- **《数字修正对照总表.csv》**（本目录）：15 项检验的初稿数字↔新数字逐项对照；
- 15 个子文件夹：每个含 `code/`（可复跑脚本）、`results/`（结果 CSV）、`figures/`（图）、`README.md`（四段式：检验目的与初稿问题 / 数据与模型 / 结果解读 / 文本修改建议）。

## 三、口径决议记录

1. **方向一致率**：统一采用"剔除零变化月"口径（新 05 口径），公共窗口 2002-01 ~ 2019-03；pooled 与逐国中位同时报告（依据：07 号检验）。
2. **四库国家数**：凡"四库"联合分析均为 **11 国**（清华库名义 12 国中 Pakistan 不在 25 国贸易面板）；初稿"四库 12 国"全部改为 11 国（依据：14 号 A3）。
3. **公共窗口**：跨库比较（相关性、命中率、一致率）统一 2002-01 ~ 2019-03；PPML 基准用全面板 2002-01 ~ 2025-10，但 ICEWS 规格的结论以截断至 2023-04 为准（ICEWS 2023-05 起为前向填充常数；Phoenix 2019-04 起为填充）（依据：14 号 B1-B6、10 号检验）。
4. **事件库**：统一为 **712 条** 现行版（2026-07-28 修订：剔除 1 条 2001-10 日本"Working visit to China for bilateral summit"越界事件，超出 2002—2025 研究窗口；该事件从未进入任何估计样本，全部回归结果不变）；旧文件出现的 719/713/278/275 等计数不再引用（依据：14 号 C1-C2、2026-07-28 事件库核查）。
5. **累计效应规格**：统一 GD-Total 规格（出口累计 0.0794、进口 0.1063、倍数 1.34）；不得再混用 GD-Import 规格（依据：15 号检验）。
6. **多重检验**：17 类事件报告 BH q 值（by_trade 口径），p 与 q 必须区分标注；q<0.05 仅"战略定位负面→进口"（依据：13 号检验）。
7. **制裁表述**：必须三维度并列报告（进口 +26.2%/+26.8%、出口 -26.4%/-33.0%、总贸易 -15.3%/-19.8%）并注明设定依赖（含 Event_Negative 才显著）与疫情期不可识别（依据：06 号检验）。
8. **百分数口径**：制裁等事件 dummy 的效应一律以 exp(β)-1 换算报告（依据：06 号检验）。
