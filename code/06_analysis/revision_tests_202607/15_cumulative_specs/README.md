# 15 出口进口累计规格统一

## ① 检验目的与对应的初稿问题（3.3 核查 1d/1e）
初稿 4.3："累计六个月效应为 0.0823……出口累计为 0.092（9.2%），进口累计为 0.117（11.7%）——进口对政治信号的响应幅度约为出口的 1.3 倍"。核查发现 0.092/0.117 取自 **GD-Import 规格**（伙伴→中国方向冲击），与全文声明的基准（几何平均 **Aggregated** 对应 GD-Total 规格）不一致。

## ② 数据来源
`新PPMLHDFE/01_连续分数PPML/01_基准传导_季度冲击/检验结果CSV/GDELT/irf_all.csv`（h=0 行的 cum 列）。

## ③ 结果解读（results/cumulative_specs.csv）

| 规格 | 出口累计 | 进口累计 | 总贸易累计 | 进口/出口 |
|---|---|---|---|---|
| **GD-Total（基准，Aggregated）** | **0.0794** | **0.1063** | **0.0823** | **1.34** |
| GD-Import（伙伴→中国方向） | 0.0921 | 0.1171 | 0.0962 | 1.27 |
| GD-Export（中国→伙伴方向） | 0.0533 | 0.0777 | 0.0560 | 1.46 |

- 初稿总贸易 0.0823 用的是 GD-Total，而出口/进口 0.092/0.117 用的是 GD-Import——同一句话内混用两种规格。
- 统一为 GD-Total 后：出口累计 0.079（7.9%）、进口累计 0.106（10.6%），进口/出口倍数 1.34（"约 1.3 倍"仍成立）。
- 附：GD-Total 总贸易逐期 p 值：h=0..6 = .026/.018/.027/**.081**/.042/.023/.022——"全部七期显著"应改为"除 h=3 (p=0.081) 外各期显著"。

## ④ 文本修改建议
- 4.3 原句"出口累计为 0.092（9.2%），进口累计为 0.117（11.7%）——进口对政治信号的响应幅度约为出口的 1.3 倍"→"出口累计为 0.079（7.9%），进口累计为 0.106（10.6%）——进口响应幅度约为出口的 1.3 倍（GD-Total 基准规格；GD-Import 方向规格下为 0.092/0.117，倍数 1.27，见附录）"。
- 4.3 原句"GDELT 的总贸易 IRF 在全部七个 horizon 上均为正向且 p<0.05"→"在全部七个 horizon 上均为正向，其中六期 p<0.05（h=3 时 p=0.081）"。
