# 12 相关系数系列修正

## ① 检验目的与对应的初稿问题（C14）
初稿 4.1 节与摘要中一组相关系数存在类型误标、n 值错误、口径混用与全称判断错误。本表从 `3.1/01_四库多种算法相关性分析_R/output/tables/` 直接生成正确值与替换方案。

## ② 数据来源
`country_level_correlations.csv`（逐国×配对×算法×方向，公共窗口 2002-01~2019-03，n=207）、`summary_by_algorithm.csv`、`summary_by_pair.csv`。基准口径：几何平均 + Aggregated 方向（与初稿 3.4 节声明一致）。

## ③ 结果解读
见 `results/corrections_4_1.csv`，8 条修正。要点：
- 印尼 GDELT-清华：-0.33 是 **Pearson**；Spearman=-0.401，n=207（"n=55"系误读 summary 表的 11 国×5 算法组合数）。
- 印尼 Phoenix-GDELT 基准 Spearman=0.246，非 0.11。
- 五算法 GDELT-ICEWS Spearman 中位数正确值为 0.234/0.276/0.239/0.219/0.116，真实排序为绝对值加权>算术>几何>中位数>SQM——初稿"几何>算术"与实际相反，"排序稳定无反转"的表述需限缩。
- "CCC 在所有配对和算法下均低于 Spearman"不成立（2250 行中 462 行反例；Phoenix-清华配对中位数即为例外），应改为"CCC 中位数普遍低于 Pearson/Spearman 中位数（Phoenix-清华配对除外，两者均接近零）"。
- 印度三配对基准下全负成立，但 SQM 算法下 GDELT-清华=+0.076、Phoenix-清华=+0.112 为正，需注明跨算法例外。
- 东亚梯度句：0.48–0.63 是 GDELT-ICEWS **单配对**值（日 0.633/越 0.593/菲 0.589/韩 0.477）；"0.41"无出处；菲律宾无清华数据，不存在"四库一致性"。
