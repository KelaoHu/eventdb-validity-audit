# 03 换届与波动率重估

## ① 检验目的与对应的初稿问题（C4）

初稿 4.2（draft_full.txt [130]）声称："领导人换届频次与政治指数波动率之间存在显著的负相关（Pearson r=-0.60, Spearman ρ=-0.70）……日本……12 个月滚动标准差仅为 0.73——是全部 25 国中最低的……新加坡……其波动率（1.04）是日本 3 倍以上"，并以此展开"官僚政治模型解释日本制度连续性"的机制论证。核查发现这些数字与全新事件研究法 04 模块现行输出（新数据管线 scores_v3）完全不符。本检验：(a) 定位初稿数字来源；(b) 以新数据为准重估；(c) 给出新旧对照。

## ② 数据与方法

- **新数据（正式口径）**：`全新事件研究法/04_领导人换届效应与双边关系波动/results/country_metrics.csv` 与 `robustness/m4_robustness_vol_measures.csv`（25 国，GDELT 与 ICEWS 两库，2002–2025，scores_v3）。波动率两种测度：12 个月滚动 sd 均值（vol_sd12m）、12 个月滚动 range 均值（vol_range12m）。换届频次 n_turnovers 来自 `data/leaders.csv`（实权职位口径）。
- **旧数据（初稿数字来源）**：`事件研究法（25国）/领导人换届效应与双边关系波动/检验结果CSV/`（旧数据管线）。
- 代码：`code/generate.R`；结果：`results/turnover_volatility_redone.csv`（25 国明细）、`results/correlation_summary.csv`、`results/old_vs_new_comparison.csv`；图：`figures/turnover_vs_volatility.png`（320 dpi）。

## ③ 结果解读

**初稿数字来源已定位**：旧模块（旧数据管线）Aggregated 方向 Pearson r=-0.5403 (p=0.0053)、Spearman ρ=-0.5958 (p=0.0017)；日本 avg_sd=0.7345；新加坡=1.0028。初稿的"-0.60/-0.70/0.73/1.04"即来自旧数据（且有夸大：r 实为 -0.54/-0.60）。**即便在旧数据中，日本也只是第 4 低（0.7345，澳大利亚 0.5527 最低），新加坡仅为日本的 1.37 倍**——"25 国最低""3 倍以上"在任何版本中都不成立。

**新数据重估（正式结论）**：

| 库 × 测度 | Pearson r (p) | Spearman ρ (p) |
|---|---|---|
| GDELT × sd12m | -0.1277 (0.543) | -0.1021 (0.627) |
| GDELT × range12m | -0.0961 (0.648) | -0.0453 (0.830) |
| ICEWS × sd12m | +0.0502 (0.812) | -0.0064 (0.976) |
| ICEWS × range12m | -0.0016 (0.994) | -0.0752 (0.721) |

新数据下换届频次与波动率**无任何显著相关**（旧数据的显著负相关不可复现，系旧数据管线产物）。日本在新数据中 sd12m=0.6531（第 3 低，美国 0.5682 最低）；新加坡 0.8167，为日本的 1.25 倍。日本 2006–2012 六位首相、新加坡 23 年 3 位领导人的史实与 leaders.csv 相符，但跨国相关论证与"3 倍"对比均不成立。

> "在新版数据管线下，领导人换届频次与政治指数波动率之间不存在显著相关（GDELT：Pearson r=-0.128, p=0.543；ICEWS：r=+0.050, p=0.812；25 国）。旧版数据曾显示显著负相关（r=-0.540, p=0.005），但该结果不可在新数据上复现，本文不予采信。国别案例显示：日本在 2006–2012 年经历六位首相更替，但其政治指数波动率（12 个月滚动标准差 0.653）处于 25 国最低组（第 3 低）；新加坡领导人高度稳定（23 年 3 位），波动率（0.817）反而略高于日本。这些案例事实提示领导人更替与双边关系波动之间不存在简单的跨国对应关系。"
