# 11 M1 事件研究显著性补算

## ① 目的与对应初稿问题

对应初稿问题 **C13**。初稿 4.2 节（draft_full.txt 第 [129] 段）声称：

> "GDELT 的事件后冲击幅度最大且持续最久——在 h=10 后仍显著高于基线水平（p<0.05）。ICEWS 的幅度最小、衰减最快……Phoenix 介于两者之间。"

该表述无任何结果文件支撑（01 模块的 `event_study_metrics.csv` 只有响应值、无 p 值，且基线为 t-3..t-1）。本模块在 01 模块事件研究框架下重算响应并补算显著性。

## ② 数据与方法

- **事件**：`events_713.csv` 中排除领导人访问后的正/负事件（与 01 模块一致）。
- **分数**：`scores_v1_4DB_2019.csv`（四库可比样本，2002-01 至 2019-12，11–12 国；Phoenix 数据本身截至 2019-12）。
- **响应定义**：response(h) = value(t+h) − baseline，baseline = t−12 至 t−7 共 6 个月的均值（要求至少 4 个月有数据），h ∈ {0,1,3,6,12}。h=12 超出 t=0±6 的核心窗口，用于持续性检验。
- **显著性**：按事件聚类的 bootstrap（每组 500 次，对事件有放回重抽样后重算均值），报告 bootstrap SE、2.5%/97.5% 分位 CI 与双侧 p_boot；另报告单样本 t 检验 p 值作对照。
- 进入估计的事件数：负面约 41 个、正面约 58 个（受 v1 样本国别覆盖与基线要求限制，少于 09 模块 25 国命中率样本的 109/166）。
- 复现：`cd code && Rscript generate.R`。

## ③ 结果解读

**负面事件——真实幅度排序与初稿相反**（响应均值，全部 p_boot<0.001 at h=0）：

| h | GDELT | ICEWS | Phoenix | 清华 |
|---|---|---|---|---|
| 0 | −1.009*** | −1.095*** | **−1.979***（最大）** | −0.787***（最小） |
| 1 | −0.816*** | −0.893*** | −1.616*** | −0.893*** |
| 3 | −0.536*** | −0.403** | −1.239*** | −1.009*** |
| 6 | −0.315** | −0.242（ns） | −0.553** | −1.249*** |
| 12 | −0.409** | −0.333（ns） | −0.797** | **−1.388***（最大）** |

- 即时幅度最大是 **Phoenix**（h=0 约 −1.98，为 GDELT 两倍），不是 GDELT；最小是**清华**，不是 ICEWS。
- 持续性：清华响应**单调加深**且在所有 horizon 上 p<0.001，是持续性最强者；GDELT 与 Phoenix 在 h=12 仍显著（p≈0.012），ICEWS 从 h=6 起失去显著性。"h=10(h=12) 后仍显著"并非 GDELT 独有——清华、Phoenix 同样满足。
- "ICEWS 衰减最快"仅在"最早失去统计显著性"意义上成立；其 h=6/12 点估计与 GDELT 接近。

**正面事件——四库在所有 horizon 上均不显著**（最小 p：ICEWS h=0 为 0.080，清华 h=12 为 0.084）。点估计普遍在 +0.1~+0.3 之间但置信区间全部跨零。即政治指数对负面事件的响应显著、对正面合作事件无统计上可辨识的响应，存在强正负不对称性。

## ④ 文本修改建议

draft_full.txt 第 [129] 段原句：

> "GDELT 的事件后冲击幅度最大且持续最久——在 h=10 后仍显著高于基线水平（p<0.05）。ICEWS 的幅度最小、衰减最快，与其分类精度高但信号强度保守的 BBN ACCENT 设计原则一致。Phoenix 介于两者之间……均在 GDELT 上表现最强，在其他库上依次递减，与命中率排序一致。"

建议改写为（要点）：

1. 删除"GDELT 幅度最大""ICEWS 幅度最小""Phoenix 介于两者之间"三处排序表述；
2. 改为：负面事件的即时响应以 Phoenix 最大（h=0 约 −2.0），ICEWS 与 GDELT 居中（约 −1.0），清华最小（约 −0.8）；但清华响应随时间单调加深，至 h=12 达 −1.4 且全程 p<0.001，持续性最强；GDELT 与 Phoenix 在 h=12 仍显著（p<0.05），ICEWS 自 h=6 起不再显著；
3. 必须补充正负不对称结论：四库对正面合作事件的响应在所有 horizon 上均不显著，事件研究的显著响应完全由负面事件驱动；
4. "均在 GDELT 上表现最强、与命中率排序一致"一句在 M1 维度不成立，应限定为命中率与贸易回归维度，或删除。
