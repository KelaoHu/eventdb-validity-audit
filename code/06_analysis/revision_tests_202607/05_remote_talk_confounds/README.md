# 05 远程通话混淆控制

## ① 检验目的与对应初稿问题（C9）

初稿 3.5 节 [100] 声称对远程通话执行了两步识别策略（控制同期非访问负面事件 + 高/低混淆组分别估计 IRF），4.3 节 [140] 据此声称"远程通话的负效应降至不显著"。核查（C9）发现该识别策略**从未实际执行**，无任何可溯源代码与结果。本检验按初稿描述首次实际执行该策略，判断"控制/分组后远程通话负效应是否不再显著"。

## ② 数据与模型设定

- 面板：`新PPMLHDFE/data/panel_clean.csv`（25 国 × 2002.01–2025.10 月度）；事件面板 `02_事件驱动PPMLHDFE/00_事件面板构建/中间数据/event_panel_ready.csv`（含 V_RemoteTalk 等访问虚拟变量）。
- 负面事件集（模块 7 口径）：`events_713.csv` 中 `event_type_original != "leader_visit"` 且 `impact == "negative"` 的事件，n=110（9 个负向类别，与 07_政治信任非对称性/robustness 的 negative n≈111 对应）。初稿"三类及以上负面事件"在旧代码中无任何可操作定义，故采用模块 7 实际使用的负面事件全集。
- (a) PPML-HDFE：`fepois(Trade ~ V_RemoteTalk + V_China_Outbound + V_Partner_Inbound + NegEvent + ln_GDP_product + ln_ER + FTA_Dummy | ISO + YearMonth)`，cluster=~ISO，与 02 模块完全一致；NegEvent 两种口径：`Neg_Same`（同月有同国负面事件）、`Neg_PM1`（t-1/t/t+1 任一月有）。三因变量（Trade_Total/Exports/Imports）。
- (b) 事件研究 IRF：18 条远程通话事件（17 条可用，US 2025-11 超出面板），口径参照全新事件研究法 01 模块（基准期 = t-3..t-1 均值），IRF_i(h)=log(Trade_{t+h})−基准，h=−6..+6。主分组 = 初稿口径（±1 月内是否有同国负面事件）；辅助分组 = 疫情危机窗口（2020.01–2021.12）内/外，作为"伴生危机"的可操作代理。
- 代码：`code/05a_phone_confound_ppml.R`、`code/05b_phone_irf_by_group.R`；输出 `results/phone_call_confound.csv`、`results/phone_call_irf_by_group.csv`、`figures/phone_call_irf_groups.png`（英文，300dpi）。

## ③ 结果解读

**(a) 控制同期负面事件后，远程通话系数几乎不变、仍显著：**

| 规格 | V_RemoteTalk (Imports) | NegEvent 系数 |
|---|---|---|
| 基线（不控制） | **−0.0850 (p=0.006)** | — |
| +Neg_Same（同月） | **−0.0851 (p=0.006)** | −0.0068 (p=0.752, 不显著) |
| +Neg_PM1（±1月） | **−0.0857 (p=0.007)** | −0.0089 (p=0.716, 不显著) |

总贸易/出口维度同样：−0.131→−0.132、−0.181→−0.182，均 p<0.001 不变。诊断显示：16 个远程通话国家-月单元与同月或 ±1 月负面事件的**重叠数为 0**（18 条通话与同国最近负面事件的最小时间距离为 61 天/2 个月）——初稿预设的"时间重叠"在 713 事件库中根本不存在，混淆在数据上没有载体。同期负面事件虚拟变量本身对贸易也无不显著影响。

**(b) 分组 IRF：** 按初稿口径，高混淆组事件数为 **0/17**，分组比较不可执行（这本身就是结论）。辅助的疫情窗口分组显示与混淆解释**相反**的符号：危机窗口内通话（n=9）后进口相对基准**上升**（h=0 +0.094，h=1 +0.192），窗口外通话（n=8）后下降（h=0 −0.067，h=1 −0.106），组间差 h=1 为 +0.298 (p=0.0007)。即 PPML 负系数并非来自"通话与危机伴生压低贸易"，而是 YearMonth FE 的月内跨国去均值：2020–21 年中国整体贸易繁荣期，发生通话的国家相对当月其他国家贸易偏低；通话国自身贸易的绝对水平在通话后是上升的。

**结论：初稿的混淆解释被证伪。** 控制后远程通话负效应**仍然显著**（−0.085，p≈0.006），"负效应降至不显著"的论断不成立。

## ④ 文本修改建议

1. [100] 整段（"关于远程通话的识别策略。……如果两组效应无差异，则支持信号形式本身的解释。"）：所述策略已补做但结果与预设相反。应改写为："我们控制同期（同月及±1月）非访问负面事件后远程通话系数不变（−0.0851/−0.0857，p≈0.006），且在 713 事件库中远程通话与同国负面事件在 ±1 月内的重叠为零、高混淆组无事件可分——混淆解释不成立。远程通话的负系数反映的是月内相对效应而非绝对贸易下降。"
2. [140] "但在通过方法节描述的识别策略——控制同期非访问负面事件并对高混淆组和低混淆组分别估计 IRF——处理后，远程通话的负效应降至不显著。" → 必须删除或改为："控制同期负面事件后该负效应保持不变（β=−0.085，p=0.006），不能归因于伴生危机事件的混淆。"
3. 摘要 [3] 与引言 [10] 中"远程通话因多与危机事件伴生，在控制同期负面事件后其贸易效应不再显著——这表明观察到的表面负效应主要来自伴生危机的混淆"两句 → 删除"不再显著"与"混淆"论断，改为相对效应表述。
4. "模块 7 的负面事件集中的三类及以上负面事件"无溯源定义，若保留该表述需补明确定义；建议直接写"模块 7 的负面事件集（非访问负面事件，n=110）"。
