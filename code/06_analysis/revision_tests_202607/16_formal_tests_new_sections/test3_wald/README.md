# 16-检验3 正面 vs 负面事件 IRF 对称性：Wald 检验

## ① 检验目的与对应初稿问题

初稿 4.5 节（M7 模块，`3.2 双边关系分析基于月度政治分数\全新事件研究法\07_政治信任非对称性`）声称：政治信任存在非对称性——负面冲击（GDELT h=0 −0.458、ICEWS −0.473）幅度大于正面（+0.255/+0.157），且正面响应 h=3 后转负。但 M7 是正/负两组**各自独立**的事件均值 IRF，未做同一方程内 β_pos 与 β_neg 的相等性检验。本检验把两类暴露放进同一局部投影方程，逐 horizon 做 Wald 检验。

## ② 数据与模型设定

- 数据与暴露口径同 M7：剔除 `leader_visit`，168 正 / 110 负条事件聚合为国家×月暴露虚拟变量；分数库 GDELT 主、ICEWS 稳健性。
- 主设定（与 M7 shock 口径一致）：y_{i,t,h} = score_{i,t+h} − mean(score_{i,t−1..t−3})，
  y = β_pos·PosExp + β_neg·NegExp + Country FE + Year-Month FE，双向聚类（country+month），h=0..6，R `fixest::feols`。
- 检验 1（对称性）：每个 h 做 Wald 检验 H0: β_pos + β_neg = 0（即 β_pos = |β_neg|，幅度对称、方向相反），χ²(1)。
- 检验 2（"正面响应 h≥3 后 ≤0"）：(i) 逐 h 报告 β_pos 双侧 p 与单侧 p（H1: β_pos<0）；(ii) 把 h=3..6 四个 horizon 堆叠为长面板（country×horizon 与 month×horizon 固定效应，聚类到 country-month 单元），联合 Wald 检验 H0: β_pos(3)=β_pos(4)=β_pos(5)=β_pos(6)=0。
- 稳健性设定：因变量取 score 水平值（`spec=level`，该设定下事件自选择于分数水平，正响应各 h 显著为正，仅作对照）。

## ③ 结果解读（新数字，change 主设定）

**逐 horizon 估计与对称性 Wald 检验**

| 库 | h | β_pos (p) | β_neg (p) | 幅度比 |β_pos/β_neg| | Wald χ²(1) | p |
|---|---|---|---|---|---|---|---|
| GDELT | 0 | **+0.260 (0.0026)** | **-0.428 (0.0005)** | 0.61 | 1.64 | **0.201** |
| GDELT | 1 | +0.126 (0.166) | -0.200 (0.051) | 0.63 | 0.39 | 0.530 |
| GDELT | 2–6 | 均不显著 | 均不显著 | — | <0.6 | >0.47 |
| ICEWS | 0 | **+0.252 (0.021)** | **-0.710 (9.4e-5)** | 0.36 | 5.51 | **0.019** |
| ICEWS | 1 | +0.074 (0.652) | -0.251 (0.170) | 0.29 | 0.53 | 0.469 |
| ICEWS | 2–6 | 均不显著 | 均不显著 | — | <2.0 | >0.16 |

**正面响应 h≥3 联合检验**：GDELT 堆叠联合 Wald F(4)=0.88，**p=0.474**；ICEWS F(4)=1.08，**p=0.366**——不能拒绝"正面响应 h≥3 后为零"。逐 h 看，正面响应在 h=3..6 全部不显著（GDELT p=0.21~0.92；仅 h=6 点估计 -0.133，单侧 p=0.101，**未达显著的"转负"**）。

三点结论：
1. **非对称性的点估计模式成立**：h=0 时负面冲击幅度大于正面（GDELT 比率 0.61、ICEWS 0.36），与 M7 方向一致。
2. **但正式对称性检验只在 ICEWS h=0 拒绝对称**（p=0.019）；GDELT h=0 不能拒绝（p=0.201）——GDELT 下"负面显著强于正面"不能按 5% 水平断言，只能说点估计方向一致。h≥1 两库均不拒绝对称。
3. **"正面响应 h≥3 后转负"应修正为"衰减至与零无显著差异"**：联合检验支持 h≥3 正面效应为零（p=0.47/0.37），但没有任何一个 horizon 的正面响应显著为负（最小单侧 p=0.101）。

## ④ 文本修改建议（写入 4.5 节草稿）

> "将正、负事件暴露纳入同一局部投影方程后，h=0 时负面冲击的点估计幅度大于正面（GDELT：-0.428 vs +0.260，幅度比 0.61；ICEWS：-0.710 vs +0.252，幅度比 0.36），与信任非对称性一致；但对称性 Wald 检验（H0: β_pos+β_neg=0）仅在 ICEWS 上于 5% 水平拒绝（χ²=5.51，p=0.019），GDELT 上不能拒绝（χ²=1.64，p=0.201），故非对称性宜表述为点估计层面的方向性证据，在 ICEWS 口径下具有统计支持。正面响应在事件后第 3 个月起衰减至与零无显著差异（h=3..6 联合 Wald：GDELT p=0.474，ICEWS p=0.366），但未观察到显著为负的反转。"

- 将"正面响应 h=3 后转负"改为"正面响应 h=3 后衰减至不显著"；删除暗示显著反转的表述。
