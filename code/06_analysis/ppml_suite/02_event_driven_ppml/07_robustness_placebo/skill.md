# 07_稳健性与安慰剂 Skill

## 适用场景

当你想验证事件效应在不同模型设定、样本选择下是否稳健，并排除随机因素时，使用本 Skill。

## 科学问题

事件效应是否只是特定样本、控制变量或模型选择的结果？随机置换事件是否也能得到类似系数？

## 输入数据

- `00_事件面板构建/中间数据/event_panel_ready.csv`

## 核心方法

### 稳健性

| 检验 | 设定 |
|------|------|
| 加入 ln_GDP | 控制变量增加 |
| 排除美国 | 样本选择 |
| 排除疫情期 | 样本选择 |
| 双向聚类 | 标准误聚类到 `ISO + YearMonth` |
| OLS 对比 | 线性固定效应模型 |

### 安慰剂

对每个事件变量，在国家内随机置换事件发生时间，重复 `N_PERM` 次，构建安慰剂系数分布，计算真实系数在安慰剂分布中的尾部概率。

- `检验结果CSV/07_placebo_tests.csv`

## 结果解读

- 稳健性：真实系数在不同设定下方向稳定，则结果可信。
- 安慰剂 p 值 < 0.10：真实系数显著异于随机分布，事件效应不是偶然。

## 常见陷阱

1. **OLS 对比**：贸易额为右偏正数，OLS 可能给出异常大系数，仅作方法对比，不宜作为主要结论。
2. **安慰剂计算成本**：`N_PERM` 默认为 100，提高会显著增加运行时间。
3. **ln_GDP 共线性**：`ln_GDP` 与 `ln_GDP_product` 高度相关，可能被自动剔除。
