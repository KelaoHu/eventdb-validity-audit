# 03_17 类事件异质性 Skill

## 适用场景

当你想在更细粒度上识别哪些具体事件类型显著促进或抑制贸易时，使用本 Skill。

## 科学问题

在 17 类事件中，哪些对贸易有显著正向/负向效应？经贸互利合作、战略伙伴关系提升、经贸制裁、科技管制等分别如何影响贸易？

## 输入数据

- `00_事件面板构建/中间数据/event_panel_ready.csv`
- 17 类变量：`Cat_*`（如 `Cat_经贸互利合作`、`Cat_经贸制裁/关税壁垒` 等）

## 核心模型

以样本中频数最高的类别为参照组，联合回归：

```
fepois(Trade ~ Cat_类别1 + Cat_类别2 + ... + Controls | ISO + YearMonth, cluster = ~ISO)
```

变量名含 `/` 等 R 公式特殊字符，需用反引号包裹，如 `` `Cat_经贸互利合作` ``。

## 输出文件

- `检验结果CSV/03_seventeen_category_effects.csv`
- `图片/fig03_seventeen_category_forest.png`
- `图片/fig03_category_heatmap.png`

## 结果解读

- 系数 > 0 且显著：该类别相对参照组促进贸易。
- 系数 < 0 且显著：该类别相对参照组抑制贸易。
- 稀疏类别（如战略定位负面、安全威胁）可能因与高维 FE 共线而被自动剔除。

## 常见陷阱

1. **参照组选择**：默认以频数最高类为参照，不同参照组会改变系数解释。
2. **稀疏类别**：事件数 < 10 的类别通常无法被 FE 模型识别。
3. **R 公式特殊字符**：中文类别名含 `/`、`(` 等，需用反引号引用。
