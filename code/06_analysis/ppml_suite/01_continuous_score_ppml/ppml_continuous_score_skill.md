# PPML-HDFE 连续分数政治冲击分析 Skill

## 适用场景

当你想用**连续型政治关系分数**（而非离散事件）来研究政治关系变化对双边贸易的影响时，使用本 Skill。

典型问题：
- 政治关系“温度曲线”上升或下降，会如何影响中国与贸易伙伴的进出口？
- 不同数据库（GDELT / ICEWS / Phoenix / Tsinghua）测度的政治关系，结论是否一致？
- 政治冲击的影响是短期还是长期？是否存在反向因果？


## 核心思想

把政治关系当成一条**连续波动的时间序列**，通过以下步骤研究其对贸易的影响：

1. **提取意外冲击**：从政治分数中剔除可预测趋势（如 AR(1) 残差或一阶差分），保留“意外变化”。
2. **局部投影 IRF**：观察冲击发生后 0–6 期（或更长）内贸易如何响应。
3. **PPML-HDFE**：用泊松伪最大似然估计处理贸易额非负、右偏的分布特征，同时控制国家和时间高维固定效应。
4. **多库交叉验证**：比较 GDELT、ICEWS、Phoenix、Tsinghua 的结果，避免单一数据库的测量偏误。


## 数据要求

### 必备数据

1. **经济面板**（`data/panel_clean.csv`）
   - 必须包含：`ISO`、`Country`、`month`、`Trade_Total`、`Trade_Exports`、`Trade_Imports`、`ln_GDP_product`、`ln_ER`、`FTA_Dummy`
   - 来源：`3 实证结果/数据/经济数据库/`（IMF、WTO 等）
   - 时间范围：建议 2002–2025，月度或季度

2. **政治分数**（`3.2 双边关系分析基于月度政治分数/全新事件研究法/data/`）
   - `gdelt_scores.csv`：GDELT 月度分数
   - `icews_scores.csv`：ICEWS 月度分数
   - `phoenix_scores.csv`：Phoenix 月度分数
   - `tsinghua_scores.csv`：清华指数
   - 格式：长表，每行是一个国家-月份-分数类型组合

### 不使用的数据

- **`自建事件库_25国_17类_713条事件.csv`**：这是人工标注的离散事件库，用于事件研究法（event study），不用于连续分数 PPML-HDFE。


## 标准分析流程

### 第一步：数据准备

```r
panel <- load_panel(ROOT_DIR)      # 读取经济面板
scores <- load_scores(ROOT_DIR)    # 读取四库政治分数
panel_db <- prepare_panel_db(panel, scores)  # 合并、标准化、提取 AR(1) 残差
```

关键操作：
- 对 GDELT/ICEWS/Phoenix 用水平值标准化。
- 对 Tsinghua 做一阶差分（处理单位根）后再标准化。
- 生成 `u_Agg`、`u_CHN_Partner`、`u_Partner_CHN` 三个 AR(1) 残差冲击。

### 第二步：基准 IRF

对每个数据库、每个贸易变量、每个冲击方向，跑 h=0..6 的局部投影：

```r
Trade_{t+h} = β_h * Shock_t + Controls_t + FE_ISO + FE_YearMonth + ε_t
```

使用 `fixest::fepois`，聚类标准误到国家。

### 第三步：稳健性检验

| 检验 | 目的 | 脚本参考 |
|------|------|----------|
| 方向分解 | 区分中国→伙伴 vs 伙伴→中国的冲击 | `02_方向分解` |
| 干净面板 PPML | 用水平分数做联合分布滞后 | `03_干净面板PPML` |
| AR(1) 残差回归 | 剔除可预测趋势后的稳健性 | `04_AR1残差回归` |
| 频率响应扫描 | 不同窗口长度下的效应稳定性 | `05_频率响应扫描` |
| 前向效应 | 检验反向因果和领先滞后结构 | `06_前向效应` |
| 信噪比标度律 | 比较不同数据库的序列记忆性 | `07_信噪比效应量标度律` |

### 第四步：交叉验证

比较四个数据库的 IRF 形状、符号、显著性。若结论一致，可信度较高；若不一致，需讨论测量差异。


## 结果解读指南

### IRF 系数

- 系数为正：政治关系改善 → 贸易增加。
- 系数为负：政治关系恶化 → 贸易减少（或关系改善反而减少贸易）。
- 显著性：通常看 p < 0.05，但连续分数分析中也可关注 p < 0.10。

### 累计效应 cum

- h=0..6 系数之和，反映冲击在 6 期内对贸易的总影响。
- cum 与 h0 差异大，说明效应在不同时期方向或强度有变化。

### 前向效应中的 h < 0

- 若 h < 0 显著，说明未来政治冲击与当前贸易相关，可能存在：
  - 反向因果（贸易影响政治）
  - 共同趋势（第三方因素同时影响两者）


## 常见陷阱

1. **单位根问题**
   - Tsinghua 指数通常为高度自相关序列，直接使用水平值会导致伪回归。必须做一阶差分。
   - 检查：`C_scaling.csv` 中 Tsinghua 的 rho 应明显低于其他库。

2. **多重共线性**
   - 联合分布滞后模型中，多个滞后项可能高度相关，导致系数符号不稳定。
   - 建议：对比联合回归和单独回归的结果。

3. **样本量差异**
   - Tsinghua 数据通常只覆盖 11 国（部分国家缺贸易数据），解释需谨慎。
   - Phoenix 数据截止到 2019 年左右，与其他库时间范围不同。

4. **数据库异质性**
   - GDELT 新闻驱动，可能对负面事件过度反应。
   - ICEWS 人工编码，事件密度较低。
   - Phoenix 结构化事件，记忆性较强。
   - Tsinghua 专家指数，平滑度高。
