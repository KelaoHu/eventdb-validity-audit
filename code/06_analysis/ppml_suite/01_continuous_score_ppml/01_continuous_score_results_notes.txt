================================================================================
01_连续分数PPML 文件夹 —— 结果说明
================================================================================

这个文件夹做的是：用“连续的政治关系分数”而不是“有没有发生某个事件”，
来看中国和 25 个主要贸易伙伴之间的政治关系变化，会怎样影响双边贸易。

简单来说，就是把政治关系当成一条每天都在波动的“温度曲线”，
温度升高（关系变好）或降低（关系变差）都会对经济产生影响。
这里要看的是：这种温度变化，会不会、过多久、在多大程度上影响贸易。

下面按子文件夹编号逐个说明。


--------------------------------------------------------------------------------
一、01_基准传导_季度冲击
--------------------------------------------------------------------------------

【做了什么】
把月度政治分数加总成季度分数，然后用统计方法提取出“意外冲击”
（也就是关系突然变好或变坏的部分），再看这个冲击发生后 0 到 6 个季度内，
中国对伙伴国的总贸易、出口、进口分别怎么变化。

这个分析方法叫“局部投影脉冲响应”（LP-IRF），不用太关心名字，
就把它理解为：在政治关系突然变化之后，追踪接下来 6 个季度贸易怎么走。

【分别用了哪四个数据库】
- GDELT：从全球新闻媒体里抓取的事件数据
- ICEWS：另一个国际事件数据库
- Phoenix：结合人工编码的事件数据
- Tsinghua：清华中外关系数据库

四个库看的是同一段中美关系、中日关系等，但算法和来源不同，
所以结果会不一样，正好可以互相验证。

【现实对应】
比如 2012 年中日钓鱼岛争端、2017 年萨德事件、2020 年中美关系紧张，
这些都会让政治关系分数突然下降。这里就是在问：
“关系变差之后，中国和这个国家的贸易会不会跟着掉？掉多少？持续多久？”

【结果怎么样】
- GDELT：政治关系变好 → 贸易增加，且对出口、进口都显著。效应在冲击后 0–6 季度都稳定存在，系数大约 0.01 左右。意思是说，政治关系每“意外变好”一个标准差，贸易额大约会上涨 1% 上下。

- ICEWS：总体来看不显著，但对出口有一些正向影响。也就是说，ICEWS 看不太出政治关系变化对整体贸易的明显作用。

- Phoenix：总贸易不显著；出口方向偏负（关系变差可能让出口下降），进口方向偏正但不显著。整体信号比较弱。

- Tsinghua：对出口有显著的负面影响。关系变差 → 中国对伙伴国出口下降。总贸易和进口不显著。但 Tsinghua 数据只覆盖 11 个国家（巴基斯坦缺贸易数据），样本比较小，解释要谨慎。

【大白话总结】
GDELT 最“乐观”：关系好就贸易好。
Tsinghua 最“悲观”：关系差就出口差。
ICEWS 和 Phoenix 信号比较弱，说不清楚。
这说明：不同的数据库对“政治关系”的测量方式不同，得出的结论也不一样，
不能只看一个数据库就下结论。


--------------------------------------------------------------------------------
二、02_方向分解
--------------------------------------------------------------------------------

【做了什么】
把政治冲击分成两个方向：
- 中国 → 伙伴国：中国对外释放的政治信号（比如中国对日本示好或示强）
- 伙伴国 → 中国：伙伴国对华释放的政治信号（比如日本对中国示好或示强）

然后分别看这两个方向的冲击，对中国出口、进口的影响是否不同。

【现实对应】
比如中国制裁澳大利亚葡萄酒，这是“中国 → 澳大利亚”方向的政治冲击；
澳大利亚对中国铁矿石加征关税或限制，这是“澳大利亚 → 中国”方向的政治冲击。
方向不同，对贸易的影响可能也不同。

【结果怎么样】
这里只用了 GDELT 数据画图。从图上看：
- 中国对伙伴国的政治信号（C2P）和伙伴国对中国的政治信号（P2C）对贸易的影响方向大体一致。
- 整体效应仍然是“关系好 → 贸易增加”。
- 两个方向的冲击对出口、进口的影响差异不明显。

【大白话总结】
至少在 GDELT 数据里，不管是中国主动释放的政治信号，还是对方国家释放的信号，
对贸易的影响都差不多：关系好就贸易好，关系差就贸易差。


--------------------------------------------------------------------------------
三、03_干净面板PPML
--------------------------------------------------------------------------------

【做了什么】
用 PPML（泊松伪最大似然估计）方法，把政治分数的当期和 6 期滞后同时放进模型，
看政治关系对贸易的“平均”累计影响。

尝试了六种政治分数变体：
- 原始分数（signed）：分数可正可负
- 绝对值分数（abs）：只看变化幅度，不看方向
- 中国→伙伴国方向分数（C2P）
- 伙伴国→中国方向分数（P2C）

【现实对应】
前面 IRF 看的是“冲击发生后的动态反应”，这里看的是“总体上，政治关系和贸易有没有关系”，
同时区分了分数的方向和幅度。

【结果怎么样】
- GDELT：原始分数对总贸易、出口、进口都有显著正影响。关系变好 → 贸易增加。但绝对值分数的影响是负的，说明方向很重要。
- ICEWS：结果比较弱，部分出口方向显著为正。
- Phoenix：结果比较弱，部分显著但不系统。
- Tsinghua：原始分数对总贸易和出口有负影响，但绝对值分数有正影响。样本只有 11 国，需谨慎。

【大白话总结】
GDELT 的政治分数和贸易正相关最清楚；其他数据库信号较弱。
同时看“方向”和“幅度”时，方向往往比幅度更重要。


--------------------------------------------------------------------------------
四、04_AR1残差回归
--------------------------------------------------------------------------------

【做了什么】
不是直接用政治分数做解释变量，而是先把政治分数里的“可预测部分”去掉，
只保留“意外冲击”部分，再用这个意外冲击去解释贸易变化。

这样可以减少“政治关系和贸易同时被某个第三方因素驱动”的干扰。

【现实对应】
比如中美两国经济同时走弱，可能贸易和政治关系一起变差。
如果直接用政治分数解释贸易，会把经济因素误当成政治因素。
用 AR(1) 残差就是尽量把“关系突然意外变化”的那部分挑出来。

【结果怎么样】
- GDELT：总贸易、出口、进口都有正影响，且不少显著。也就是说，意外变好 → 贸易增加。
- ICEWS：结果比较弱，方向不稳定。
- Phoenix：结果比较弱。
- Tsinghua：总贸易负影响，但不显著。

【大白话总结】
去掉可预测趋势后，GDELT 仍然显示政治意外冲击和贸易正相关。
但其他数据库信号较弱，说明“意外冲击”的提取方式对结果很敏感。


--------------------------------------------------------------------------------
五、05_频率响应扫描
--------------------------------------------------------------------------------

【做了什么】
改变“冲击窗口”的长度，分别看 k=1、2、3、4、6、12、24 个月后的累计效应。

【现实对应】
政治关系对贸易的影响可能是短期的（一两个月就消失），
也可能是长期的（一两年后才完全显现）。这里想看看影响持续多久。

【结果怎么样】
- GDELT：短期（k=1 到 k=6）有显著正影响，窗口拉长到 12、24 个月后效应逐渐衰减，但仍为正。
- ICEWS、Phoenix、Tsinghua：效应都比较弱，不显著或仅在个别窗口显著。

【大白话总结】
GDELT 里政治关系对贸易的影响在短中期（1–6 个月）最明显，长期会衰减。
其他数据库看不太出稳定的频率响应模式。


--------------------------------------------------------------------------------
六、06_前向效应
--------------------------------------------------------------------------------

【做了什么】
检验“政治冲击”和“贸易变化”谁先谁后。
- h = -3, -2, -1：未来的政治冲击，对现在的贸易有没有影响（反向因果）
- h = 0：同时期关系
- h = 1, 2, ..., 6：当前的政治冲击，对未来的贸易有没有影响（正向因果）

【现实对应】
是政治关系先变差，然后贸易才下降？
还是贸易先下降，然后政治关系才变差？
或者是两国经济同时出问题，导致两者一起变？

【结果怎么样】
这里只用 GDELT 数据。结果显示：
- 所有 h（包括 -3 到 6）的系数都是正的，而且很多都显著。
- 也就是说，当前的政治冲击、未来的政治冲击、过去的政治冲击，都和当前贸易正相关。

【大白话总结】
这个结果比较奇怪。它说明 GDELT 的政治分数和贸易之间不只是“政治影响贸易”这么简单，
可能还有以下两种可能：
1. 贸易好 → 政治关系好（反向因果）：经济往来多了，关系自然缓和。
2. 有第三方因素同时影响两者：比如全球经济景气时，贸易和政治关系分数一起走高。

所以不能简单地说“政治关系恶化导致贸易下降”，还要考虑双向关系和共同趋势。


--------------------------------------------------------------------------------
七、07_信噪比效应量标度律
--------------------------------------------------------------------------------

【做了什么】
计算每个数据库里政治分数的“记忆性”有多强，也就是今天的政治关系分数，
在多大程度上能被昨天的分数预测。这个指标叫 AR(1) 的 rho 系数。

- rho 接近 1：政治关系变化很慢，今天什么样，明天还什么样（噪声小，信号持久）。
- rho 接近 0：政治关系波动很大，今天好明天可能就差（噪声大，信号短暂）。

然后看 rho 大小和贸易效应之间有没有关系。

【现实对应】
有些国家间关系是“长期冷淡但稳定”（比如中日关系经常有摩擦但总体可控），
有些是“忽冷忽热、新闻很多”（比如中美关系经常因为某个事件突然紧张）。
这里想看的是：哪种关系模式对贸易的影响更强、更持久。

【结果怎么样】
四个库的 rho 值：
- GDELT：0.35
- ICEWS：0.34
- Phoenix：0.47
- Tsinghua：0.21

Phoenix 的政治分数最“稳定”（记忆性最强），Tsinghua 最“波动”。
但从贸易效应来看，rho 和累计效应之间并没有呈现出很强的规律性。

【大白话总结】
不同的数据库对“政治关系”的刻画方式确实不一样：
Phoenix 更像缓慢变化的背景温度，Tsinghua 更像短期波动的情绪。
但政治关系“稳不稳定”和“对贸易影响大不大”，这两者之间并没有简单的对应关系。


--------------------------------------------------------------------------------
八、总体结论
--------------------------------------------------------------------------------

1. 政治关系和贸易之间确实有关系，但关系方向在不同数据库里不一样。
   GDELT 倾向于“关系好 → 贸易好”，Tsinghua 倾向于“关系差 → 出口差”。

2. GDELT 的结果最一致：无论是 IRF、干净面板 PPML、AR(1) 残差回归，
   还是频率响应扫描，都显示关系变好对贸易有正向作用。

3. 前向效应检验发现 GDELT 的政治分数和贸易在所有时间方向上都是正相关的，
   这说明不能排除反向因果或共同趋势。

4. 不同数据库的结论不一致，说明“政治关系”这个变量很难用一个统一指标精确测量，
   做研究时不能只看一个数据库。

5. 本文件夹里的分析脚本都是重新编写的。旧版结果已备份到 ../archive/old_results/，
   新结果和旧结果在数值上不完全相同，因为旧版生成脚本已经丢失，
   新版脚本按当前数据结构和可复现原则重新实现。
