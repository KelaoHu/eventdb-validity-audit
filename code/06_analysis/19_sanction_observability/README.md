# 19_制裁事件进口方向可观察性检验

## 目的
为 4.4 节“对华制裁与科技管制事件的进口正效应”提供一项不依赖新回归估计的可观察性检验。通过比较事件前 1 个月（t = -1）与事件后 1–2 个月（t = +1, +2）的进口水平，判断 20%+ 量级的正效应是否建立在多数案例方向一致的基础上，还是被少数国家的极端值所驱动。

## 数据
- 输入：`PPML套件/02_事件驱动PPMLHDFE/00_事件面板构建/中间数据/event_panel_with_directional_sanctions.csv`
- 目标事件：`Cat_科技管制_对华` 与 `Cat_经贸制裁_对华` 同时取 1 的国家-月份
- 贸易变量：`Trade_Imports`（百万美元，来自 IMF DOTS）

## 口径
- 分析窗口：t = -1 为基期，t = +1 与 t = +2 为事件后期
- 变化方向：
  - Increase：事件后进口 > 事件前进口
  - Decrease：事件后进口 < 事件前进口
  - No change：两者相等（本样本未出现）
- 疫情期定义：2020-01 至 2021-06
- 不控制季节趋势或固定效应，因此是**描述性可观察性检验**，不是因果估计

## 主要发现（基于 22 个对华制裁国家-月份）

### 1. 方向分布
| 样本 | 窗口 | N | 上升比例 | 中位数变化 | 二项检验 p（H0: 上升=50%） |
|---|---|---:|---:|---:|---:|
| 全部对华事件 | t = +1 | 22 | 45.5% | -1.2% | 0.832 |
| 全部对华事件 | t = +2 | 22 | 72.7% | +5.8% | 0.052* |
| 仅科技管制 | t = +2 | 11 | 63.6% | +1.4% | 0.549 |
| 仅经贸制裁 | t = +2 | 11 | 81.8% | +6.3% | 0.065 |
| 排除疫情期 | t = +2 | 18 | 72.2% | +4.9% | 0.096 |

*注：* p < 0.10 用 * 标注。

### 2. 国家层面
- 样本高度集中于墨西哥（10 个事件）和美国（8 个事件），合计占 82%。
- 印度在 t=+1 出现 75.9% 的极端上升，但仅 1 个事件（2 个观测），对整体分布影响大。
- 澳大利亚、阿联酋、意大利在两次窗口中均表现为进口下降。

### 3. 解释边界
- t = +2 的 72.7% 上升比例在边缘上高于 50%，但二项检验仅达 p = 0.052，且小样本下对个别国家（印度、墨西哥）敏感。
- t = +1 的方向分布与 50% 无显著差异，说明“进口正效应”并非即时一致出现。
- 该检验**未控制**季节、趋势、其他事件或固定效应，因此不能替代正文 PPML 估计；其价值在于展示效应的个案基础是否稳健。

## 局限性
1. 未控制季节、年度趋势、其他同期事件。
2. 22 个观测中墨西哥与美国占绝对多数，国家异质性受限。
3. 百分比变化对进口基数小的国家敏感。
4. 这是描述性证据，不能用于因果识别。

## 对 4.4 节的启示
- t = +2 的方向分布显示多数案例（尤其经贸制裁）呈现进口上升，为贸易预期理论提供了**个案方向一致性**的初步支持。
- 但效应不是即时一致（t = +1 方向分布与随机无显著差异），且样本小、国家集中，因此结论应表述为“提示性证据”而非“稳健事实”。
