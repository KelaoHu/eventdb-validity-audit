# 09_四库事件命中率测试

以 712 条自建事件为黄金标准，测四库"事件当月（及放宽窗）指数变化方向与事件性质一致"的比例。
对应正文 4.2 节命中率排序与附录 S3 表。

## 输入
- 事件：`..\..\..\02_中间数据_分数与面板\月度分数\events_712.csv`（非访问事件子集）
- 分数：四库 `*_scores.csv`（基准期 t=−12~−7 月均值；剔除领导人互动事件）

## 输出（`code\results\`）
| 文件 | 内容 |
|---|---|
| `hit_rate_main.csv` | 4 库 × 4 窗口（W_strict/W_1m/W_2m/W_best）命中率主表 |
| `hit_data_full.csv` | 事件级明细（db × 事件 × 窗口：pre_mean/delta/hit），公共窗口等再分析的原料 |
| `四库命中率测试报告.txt` | 文字摘要 |

## 口径
- 严格窗口 W_strict = 仅事件当月；W_1m/W_2m = 放宽至后 1/2 个月；W_best = 逐库最优窗
- fair 口径（剔除 ICEWS>2023-04、Phoenix>2019-03 事件）结果见
  `..\..\重跑_公平覆盖期_202607\02_事件研究套件\fair\09_四库事件命中率测试\`——**正文引用以 fair 为准**
- 分母注意：本模块按记录层面；正文/附录按去重事件数（如 112/166=67.5%），两口径并存勿混
